01 / THE PROBLEM

You know the name.
The index should too.

Moodle’s usual A–Z participant index looks at the written name. For a class full of names like 佐藤, 鈴木, and 高橋, Latin initials aren’t much help.

The readings are already there in Moodle’s phonetic name fields. Gojūon puts them to work: choose さ to find 佐藤（さとう）, or た to find 高橋（たかはし）.

03 / A SMALL, CONSIDERED ADDITION

Fits the way your course works.

あ / ア

Readings, not guesswork

Hiragana, katakana, half-width kana, and voiced variants belong to their familiar gojūon rows. Latin initials are available for romaji readings too.

姓 + 名

Two ways to narrow it down

Filter surname and given name independently. Both work alongside Moodle’s existing participant filters, sorting, and pagination.

他

Everyone has a place

Missing or unclassified readings stay accessible under Other. Reading-based filters appear only when the viewer is permitted to see those fields.

Get the latest release ↗

GNU GPL v3 or later · PHP 8.3+

  1. Download the release ZIP

    Choose the packaged plugin ZIP attached to the GitHub release.

  2. Install in Moodle

    Go to Site administration → Plugins → Install plugins, upload the ZIP, and complete the upgrade.

  3. Set up your name readings

    Populate participants’ phonetic name fields and include them in the applicable Moodle name display format. Gojūon respects their visibility.

    You can hide the original A–Z bars in the plugin settings. Read the documentation ↗
